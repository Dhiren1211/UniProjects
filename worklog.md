# UniProject — Worklog

Project: UniProject — University Project Discovery, Portfolio & Community Platform
Stack: Next.js 16 (App Router, `/` route only, hash-based SPA navigation) + TypeScript + Tailwind CSS 4 + shadcn/ui + Prisma (SQLite) + custom cookie session auth.
Design source: `/home/z/my-project/upload/design.md` (Flokka-inspired, primary #5B5CE2, canvas #F7F7F5, Pretendard).
Requirements source: `upload/UniProject_Project_Proposal.docx`, `upload/UniProject_SRS.docx` (FR-01..FR-40).

Key architectural decisions:
- Single visible route `/` → `src/app/page.tsx` renders SPA shell; internal views switch via zustand store + URL hash (e.g. `#/explore`, `#/projects/<slug>`, `#/u/<username>`, `#/community`).
- Backend = Next.js API routes under `src/app/api/**` (no server actions).
- Auth = custom sessions: `Session` table + httpOnly cookie `uni_session`, helpers in `src/lib/auth.ts`.
- Shared API contract types in `src/components/uniproject/types.ts` — ALL agents code against it.
- Design tokens live in `src/app/globals.css`; shared UI in `src/components/uniproject/`.
